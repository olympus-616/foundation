Creating a new SFDX Plugin

As part of my “Let’s Build a Salesforce App Together” series…

Official documentation for setup. Note my instructions are very similar but include source code repository setup.

Install the latest node.js (19 at the time of this writing). I highly recommend setting up NVM on your windows or mac workstation. It has been a life-saver on multiple occasions on my node.js journey. This is not really an optional step IMHO.

>nvm install 19

Use the latest version.

>nvm use 19

Check to make sure node is working

>node --version

Update npm.

>npm update -g npm

Install yarn.

>npm install -g yarn

Install TypeScript

>npm install -g typescript

Install or update Salesforce CLI

>sfdx update

Create a new github repository to host the plugin. Clone the repo locally and navigate into the subdirectory.

>git clone git@github.com:cloudpremise/reactforce.git
>cd reactforce

Always make changes within a feature branch.

>git branch feature/scaffolding
>git checkout feature/scaffolding

Scaffold a new plugin (if brand new… if the plugin is already scaffolded skip this step)

>sfdx plugins:generate reactforce

Test the plugin manually

#Windows
>cd bin
>dev hello:org -h

#MacOS
>chmod 777 ./bin/dev
>./bin/dev hello:org -h

Link and test the plugin via the sfdx cli

>cd .. #should be back in the reactforce base directory now
>sfdx plugins:link
>sfdx hello:org -h

Commit the code

>git add .
>git commit -m "SFDX Plugin Scaffolding"
>git push

See the code is now pushed to the feature branch in github.

Note… it maybe helpful to tag the scaffolded code so you can easily see the original state of the code.

>git tag -a v0.0.1 -m "SFDX Plugin Scaffolding"
>git push origin tags

You are ready to move to the next step. Publishing via NPM.
