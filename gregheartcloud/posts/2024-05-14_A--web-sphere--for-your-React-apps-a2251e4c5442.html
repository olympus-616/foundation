Do you remember WebSphere? I actually forgot this product even existed after years of dealing with Page Layouts, Visualforce, Aura, LWC, and now (and most favorably)… React.

Something happened when AWS and Salesforce took over the cloud space. Everything changed. If you can remember the days of IBM WebSphere… well I think you will enjoy this article. If you have never heard of J2EE or Spring beans… yes… SPRING beans… you may just want to move straight to the Reactforce demo.

Here are the features of the Reactforce Enterprise Portal

  1. A web application framework for building, deploying, and managing react applications hosted natively on Salesforce.com or serverless deployments using Netlify. This feature allows an enterprise to build and manage hundreds, if not thousands of react applications from within the framework. The underlining routing architecture can manage complex DNS and URL configurations, almost all of it managed by Salesforce.com’s public force.com site infrastructure. Think of this as the portlet container of IBM Websphere. However it is hosted 100% from within Salesforce so almost all of the scalability, security, and redundancy is provided by Salesforce (or Netlify in a Serverless configuration).
  2. Custom Identity Management framework. We have a prebuilt solution for logging into React applications using numerous license solutions such as Salesforce users, Salesforce Community users, Microsoft Entra ID (Active Directory if you missed that update…), AWS Cognito, Auth0, and passwordless solutions using only email or SMS. All of your organization’s Reactforce apps (think Java Portlet) can now benefit from the centralized identity management solution, allowing each Reactforce app to completely bypass any need for managing user authentication.
  3. Bleeding-Edge React development templates. You can start from scratch with Create-React-App, but why would you when we already have a template that will meet many of your user interface requirement needs? Our templates are built using Material UI or the Lightning design system, whichever use case is more appropriate for your company. And most of the important UI features that you will ever need are just sitting there… waiting to be implemented by your web developer.
  4. Express.JS style Api management platform for running your APIs natively from within Salesforce.com. This allows your react applications to be built contract first using a Restful API, or eliminate your salesforce development requirements completely using some of our premium APIs that expose a majority of Apex functionality securely to the client application.
  5. Multiple solutions for dynamic form building, meaning your business users can stand up a dynamic forms with dynamic fields and immediately expose them on a public or private URL. This can even eliminate whole systems in your enterprise if used to its fullest capability.
