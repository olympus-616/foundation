User Acceptance Testing during Agile Sprints

Should you test the current sprint or the previous sprint?

If you perform user acceptance testing during the sprint for the current sprint, you will have to shorten your development time for that sprint and freeze the uat environment with enough time to ensure that no more code is deployed on the final round of testing

If you perform UAT on the PREVIOUS sprint, developers can deploy stories up until the wire of the sprint being complete. UAT enviornment only changes once per sprint which gives testers a stable environment for the length of the sprint.

The tradeoff on this approach would be the need to have one final hardening sprint prior to release where developers can fix any final bugs in the current release.
