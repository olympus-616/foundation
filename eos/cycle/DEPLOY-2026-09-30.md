## Follow-ups (identified in Steward verification, some ticket-scoped, some fleet-scoped)

### 1. `XAI_API_KEY` missing from `/olympus/int/*` SSM
- **Scope:** Athena xAI routing tier won't work in prod until the key is added.
- **Attestation impact:** `brain_1.7.eos-5.8.md` §9-observed appendix notes it; not a code-correctness issue.
- **Fix:** SSM update — `aws ssm put-parameter --name /olympus/int/keys/XAI_API_KEY --value <key> --type SecureString`.

### 2. Poseidon seed-length in Ed25519 fingerprint compute
- **Scope:** Poseidon manifest is serving a static fallback pub key, not deriving from the loaded private key.
- **Attestation impact:** **BLOCKS `brain_1.7.eos-5.11.md` §2.10 (manifest coherence) and by extension the entire sealed-envelope kill-switch story** — clients would encrypt to a manifest pub key that Poseidon's private key path doesn't match.
- **Fix:** Correct the SSM-injected key PEM shape to what the sodium loader expects.

### 3. Version env vars missing (Ares / Athena / Hephaestus)
- **Scope:** `ARES_VERSION` / `ATHENA_VERSION` / `HEPHAESTUS_VERSION` not populated in ECS task-def.
- **Attestation impact:** cosmetic — feature detection via code paths still works; version banners just show `Version: unknown`.
- **Fix:** Task-def update — add the env vars.

### 4. Salesforce `sf` CLI not authed
- **Scope:** Expected in prod — falls back to `OLYMPUS_GRID_MASTER_URL=app.olympus-grid.com` per design.
- **Attestation impact:** none — designed behavior.

### 5. Critical event dropped: `retry_ttl_expired`
- **Scope:** One Plutus ring-buffer event evicted per W2 tier-drain behavior.
- **Attestation impact:** none — this IS the W2 kill-switch semantic per `brain_2.7.eos-1.3` §9.PLU-4 (bounded capacity ceiling with metric). Documentation of behavior, not error.
