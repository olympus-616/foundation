I’m not sure how AI knows so much about React and Salesforce, but let me just supply a little more color to the above article:

Strategic Development Advantages (My Take)

I would suggest that the component framework and open-source availability of pre-built components in React is light years ahead of the same concepts in Lightning. You have to learn both to know the differences… but let me just summarize: React = Better

I would also agree that the development process is radically better in React. Our Reactforce solution has a little secret sauce here…. we support Hot Reloading in development as well as offline proxied access to Salesforce environments. This means you can build your React app using live data from a Salesforce scratch org (or sandbox) even though your React server is running locally on your development workstation. Its basically software magic that I LOVE to show to React and Salesforce developers alike.

What ChatGPT is really failing to understand in the above article is that by deploying React sites on a native Salesforce.com org, you are bypassing all of the data integration, transformation, and on-going support necessary to manage multiple copies of your data. React talks directly to Salesforce through JavaScript remoting or LWC controllers. This allows incredible speed and flexibility to build solutions on any of your Salesforce data…. not just the important stuff that has been painfully wired through your middleware to a data warehouse or operational data store.

Enhancing User Engagement and Performance (My Take)

If you are not familiar with React, let me just say that pretty much everyone uses it. Microsoft Teams is written in React. So is Netflix and Jira. Countless others. You can install a Chrome extension that will show you anytime a website is built in React. In my own completely non-scientific study, I would suggest that the fastest, most visually compelling, responsive sites are mostly using React.

React doesn’t even compare to Salesforce Lightning. React is a single page application, which means the entire site downloads to your browser on the first load. The application unpacks itself into your browser and then makes API calls to Salesforce (or whatever data source you prefer). The end-result of a Single Page Application (SPA) means your browser almost never reloads and the entire site feels like a well built iOS app. If you are coming from the web development world, this will be fairly obvious. If you are coming from Salesforce… you simply have to see what you are missing.

We also have some secret sauce in Reactforce that makes it work absolutely seamlessly both internally on Salesforce within the Lightning or Classic experience, but even better when used to completely render the entire application such as a digital community experience. We specialize in building financial services and healthcare portals using React, hosted natively on Salesforce.com. The difference from alternative solutions is instantly noticeable, and the benefits only increase the more you learn about the entire solution.

Scalability and Enterprise Growth (My Take)

The scalability of React running on Salesforce has a few technical things to consider. First of all, the solution changes whether the React app is running internally on a page layout, or externally as a community. When running internally, you can bypass API calls completely using Javascript remoting. This basically means UNLIMITED API CALLS from React to your database. You must be rendering the React app internally and you must be using Remote Methods or Lightning Controllers to leverage this capability.

If you are rendering the React app externally in a community, you still must be mindful of Page Views (Remote Methods and Ajax Calls count as page views). We learned at scale that using React to make EXTERNAL api calls via HTTPS was a cheaper alternative at scale. You simply buy the API calls you need from Salesforce alacart and stop thinking about about 99% of the scalability issues you used to think about.

The Enterprise will love React as well. React apps can be deployed self-contained and will honor all of the security rules of the Salesforce environment its deployed to. This means that you can iterate extremely quickly with innovative creations. Or use our Reactforce Enterprise Portal (currently in Beta) to organize your entire company intranet or extranet with a robust solution that includes fully customizable user management, advanced routing configuration, and numerous site themes. Its like a portal for your portals. We are so proud of this application and I expect it to GA in the next few months.

Your application will immediately impress your customers and your project stakeholders, all while being deployed on secure and robust infrastructure that CIO’s and architects around the world love and respect.
