We aren't using this approach as much, because if you customize the login page with Visualforce or React 100% then I've found it much easier to manage the flow. I should probably update this blog!

However if you can build it all from scratch... the latest way that we do this is to use System.UserManagement.initSelfRegistration(Auth.VerificationMethod.Email, usr) once they enter their email on the login URL. Once they get the verification code we use Auth.VerificationResult res = System.UserManagement.verifySelfRegistration(Auth.VerificationMethod.EMAIL, this.identifier, this.verificationCode, startUrl);

It is very possible and very awesome to get this working... in fact we also have an SMS version only that is also very powerful but much harder to build/test without the necessary licenses from Salesforce (which they won't selll me unless I also sign up for Marketing Cloud).
