Accessing Salesforce.com Data using React

How to connect from a React application to Salesforce? There are three ways:

  1. Remote Methods
  2. Lightning Messaging
  3. Public API

A note about limits

 — Remote methods are counted as page views on an Experience Cloud. At only 1M page views per month, you can imagine how quickly this would go on a highly scalable site. And the last I heard as of 3/23 was the list price for 1M more page views was $48k/year. Check with your account executive of course.

A note on security

 — the access token is required to be in the header of the URL call from react to the salesforce api. This is a highly sensitive information and this approach allows the user to see their sessionId from Chrome’s developer tools. {{NEED TO FIGURE OUT HOW ITS PROTECTED AND WHERE IT COMES FROM}}

Considerations for Experience Cloud

 — it is about 14x more expensive to use javascript remoting within react while hosted an experience cloud. If you are accepting of the increased security risk of exposing the sessionId, using the Salesforce API is MUCH more cost effective way for building Reactforce sites on an Experience Cloud implementation!
