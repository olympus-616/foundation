Here are the steps to packaging that we used to create Olympus-Grid using 2GP 

Prereqs:

  • Salesforce CLI (I use the NPM installed version)
  • Salesforce Production Org with Environment Hub and Dev Hub enabled (business org)

Step 1: Create a New Org to Register the Namespace from the Environment Hub

  • Environment Hub → Create Org

Step 2: Create a namespace in the new org (namespace org)

  • Log into the newly created environment
  • Setup → Package Manager → Edit
  • Choose and verify a namespace. For this article I chose og_beta_8


Step 3: Link the namepace in the Namespace Registry

  • Namespace Registry is located in your business org
  • Click the “Link Namespace” button
  • Sign in with your credentials to your namespace org

The namespace now appears in your Namespace Registry

Step 4: Create the “Core” package repo

  • If you need help understanding this step message me
  • Clone the repo (we prefer SSH configuration with GPG signed commits)

Step 5: Setup a new Salesforce project

  • I used VS Code to Create my projects using the standard template


Step 6: Setup the sfdx-project.json

Step 7: Create the core package

  • notice the namespace is the FINAL namespace we want
$ sf package create --name "Olympus-Core" --description "Olympus-Grid Core Dependency" --package-type Managed --path force-app/core --target-dev-hub devhub

  • Verify the package has been created
sf package list
  • The package should be listed.

Step 8: Repeat this process above for the next package

  • In our use case, we used olympus-lib as the second package repo.
  • Verify both packages now appear in the devhub, tied to the same namespace

Step 9: Separate Metadata into Core and Lib

Step 10: Build the Core Package

sf package version create --package "Olympus-Core" --code-coverage --installation-key-bypass --wait 10 --target-dev-hub devhub
  • Notice the updates it makes to the sfdx-project.json file

Step 11: Build the Library Package

  • Specify the package dependency in the sfdx-package.json

sf package version create --package "Olympus-Lib" --code-coverage --installation-key "nobody" --wait 10 --target-dev-hub cp-biz
