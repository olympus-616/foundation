How to setup multiple ssh and git accounts on one computer

Just because I worked REALLY hard on this one I wanted to share my config for anyone that was trying to do the following:

I have numerous git accounts. Client and/or project specific. I prefer ssh for git connections and I wanted to attribute my git commits to the correct account, as well as allow each of my accounts to be connected by ssh.

I created 2 different keys from my Windows 10 computer running these command from the ~/.ssh folder

eval $(ssh-agent)
ssh-keygen -t ed25519 -b 4096 -C "caninthehat@company1.com" -f id_company1
# do the necessary stuff to create the key
ssh-add id_company1

ssh-keygen -t ed25519 -b 4096 -C "dr.s@company2.com" -f id_company2
# do the necessary stuff to create the key
ssh-add id_company2

I then logged into my separate git accounts and uploaded the public key for ssh authentication.

Here is my ssh config located at ~/.ssh/config

# Company account
Host company1.bitbucket.org
 HostName bitbucket.org
 PreferredAuthentications publickey
 AddKeysToAgent yes
 IdentityFile ~/.ssh/id_company1

# Company account
Host company2.github.com
 HostName github.com
 PreferredAuthentications publickey
 AddKeysToAgent yes
 IdentityFile ~/.ssh/id_company2

Here is my gitconfig located at ~/githubconfig

[user]
 name = sam
 email = samiam@cloudpremise.com
 
[includeIf "gitdir:D:/dev/repos/company1/"]
  path = .gitconfig-company1
  
[includeIf "gitdir:D:/dev/repos/company2/"]
  path = .gitconfig-company2

Obviously I am cloning my repos of company1 underneath the dev/repos/company1 folder and the company2 repos underneath the dev/repos/company2 folder.

Here is my .gitconfig-company1 file located at ~/.config-company1

[user]
name = Cat
user = cathat
email = caninthehat@company1.com

[core]
sshCommand = ssh -i ~/.ssh/id_company1

Here is my .gitconfig-company2 file located at ~/.config-company2

[user]
name = Dr
user = Suess
email = dr.s@company2.com

[core]
sshCommand = ssh -i ~/.ssh/id_company2

You get the point.

Now I can ssh from one computer to multiple git accounts under the appropriate identity of the git account as opposed to having to always use my own personal key.

/d/dev/repos/company1
git clone git@company1.bitbucket.org:company1account/company1repo1.git
#now connects with id_company1 ssh key and attributes company1 info

/d/dev/repos/company2
git clone git@company2.github.com:company2account/company2repo
#now connects with id_company2 ssh key and attributes company2 info

Enjoy and happy hacking. BTW these instructions worked for me on windows and I’ll update this doc if there is anything different for my Mac config.

UPDATE… this was the ~/.ssh/config file for my mac config to work correctly (I don’t know if this same file will work on windows or not):

Host company1.bitbucket.org
  HostName bitbucket.org
  IdentitiesOnly yes
  IdentityFile ~/.ssh/id_company1

Host company2.github.com
  HostName github.com
  IdentitiesOnly yes
  IdentityFile ~/.ssh/id_company2
